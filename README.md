# Autonomous Avatar Vocabulary Learning

This repository contains the Unity prototype developed as part of the bachelor thesis:

**“Modellierung eines autonomen Avatars in einer immersiven Lernumgebung des Metaversums zur Unterstützung des Englischvokabellernens”**

## Project Overview

The project explores how an autonomous avatar can be modelled in an immersive learning environment to support English vocabulary learning for students in lower secondary education.

The prototype was developed in **Unity** and implements a virtual classroom scenario in which the autonomous avatar **Mr. Lex** guides learners through vocabulary-related tasks, provides feedback, and supports the learning process through scripted interaction.

## Prototype Features

The current prototype includes:

- a virtual classroom and surrounding school environment
- an autonomous avatar named **Mr. Lex**
- an exploration phase with clickable objects
- **Task 1**: object-based vocabulary search
- **Task 2**: sentence completion with multiple-choice answers
- direct verbal and visual feedback
- progress display and score-based evaluation
- an overlay system that keeps the avatar visible when the learner leaves the classroom
- a context-sensitive help function during the first task

## Repository Structure

The most relevant folders are:

- `Assets/`
- `Packages/`
- `ProjectSettings/`

Within `Assets`, the project is structured into:

- `Assets/Scripts/` for gameplay and interaction logic
- `Assets/Characters/` for character assets
- `Assets/Environment/` for the school environment
- `Assets/Props/` for learning objects
- `Assets/UI/` for interface assets
- `Assets/Animations/` for avatar animations
